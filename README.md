1️⃣ Overview
InvTory keeps restaurant and café teams in the know with AI-driven inventory that reacts as fast as their service. We ingest menu and sales data, predict what’s running low, and surface polished dashboards so staff can act before supplies run out—without sacrificing the human touch.

✨ Features
🤖 AI-powered inventory tracking & demand forecasting that learns from historical sales.
⏱️ Real-time stock simulation that mirrors on-the-floor usage.
📦 Smart reorder recommendations with urgency scoring.
🔐 Manual updates with password protection for manager overrides.
📊 Analytics dashboard streaming live charts and KPIs.
🎨 Clean, responsive UI using Tailwind CSS, shadcn/ui, and Framer Motion micro-interactions.

🛠 Tech Stack
Next.js 15
React + TypeScript
Tailwind CSS + shadcn/ui
OpenAI API

🚀 Getting Started
git clone https://github.com/yourname/bevange.git
cd bevange
npm install
cp .env.example .env.local # ensure OPENAI_API_KEY is set
npm run dev


Add your OPENAI_API_KEY to .env.local, then open http://localhost:3000 to explore the dashboard.

⚙️ How It Works
Menu + Sales data → AI Engine (OpenAI fine-tuned prompts) → Real-time Inventory Simulator → Analytics dashboards, alerts, and manual overrides.
